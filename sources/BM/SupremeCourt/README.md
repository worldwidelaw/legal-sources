# BM/SupremeCourt — Bermuda Supreme Court Judgments

**Source:** [https://www.gov.bm/supreme-court](https://www.gov.bm/supreme-court)
**Data types:** case_law

## Coverage

~2,100 Supreme Court and Court of Appeal judgments, 2007–present (66–157 per year),
published as PDFs on per-year listing pages:

- Current year: `https://www.gov.bm/court-judgments`
- Past years: `https://www.gov.bm/court-judgments-{YYYY}` (2007–2025; 2005/2006 return 404)

Full text is extracted from the judgment PDFs. The decision date comes from the
listing anchor text where present, otherwise from the labelled date line in the PDF
header ("Date of Judgment", "Date: 23/04/2026"), otherwise from the gov.bm upload
date embedded in the file path.
