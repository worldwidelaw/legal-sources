# INTL/ACtHPRJuricaf — African Court on Human and Peoples' Rights (Juricaf)

Full-text decisions of the **African Court on Human and Peoples' Rights**
(*Cour africaine des droits de l'homme et des peuples*, ACtHPR / CADHP) — the
judicial organ of the African Union human rights system, seated in Arusha,
Tanzania — as published on [Juricaf](https://juricaf.org) by AHJUCAF.

- **Data type:** case_law
- **Language:** French
- **Access:** Juricaf JSON search API (`facet_pays:CADHP`) → per-decision HTML
  page (`/arret/{id}`), full judgment text extracted from `div#textArret`.
- **Corpus:** ~274 decisions (judgments, rulings, orders and advisory opinions).

Distinct from **INTL/ACHPR-Communications** (achpr.au.int), which covers the
African **Commission** on Human and Peoples' Rights (Banjul) decisions on
communications — a different body from the Court.

> **Vantage note:** Juricaf is fronted by an Anubis bot-challenge that blocks
> generic browser User-Agents and datacenter/Hetzner IPs. Use the
> `Legal-Data-Hunter/1.0` User-Agent (as this scraper does) from a residential
> vantage; the JSON API then returns cleanly.
