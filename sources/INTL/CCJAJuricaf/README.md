# INTL/CCJAJuricaf — OHADA Common Court of Justice and Arbitration (Juricaf)

Full-text decisions of the OHADA **Cour commune de justice et d'arbitrage
(CCJA)** — the supranational supreme court for OHADA business law, binding
across the 17 OHADA member states — as published on
[Juricaf](https://juricaf.org) by AHJUCAF.

- **Data type:** case_law
- **Language:** French
- **Access:** Juricaf JSON search API (`facet_pays:OHADA`) → per-decision HTML
  page (`/arret/{id}`), full judgment text extracted from `div#textArret`.
- **Corpus:** ~1,325 decisions.

Distinct from **INTL/OHADA-CCJA** (ohada.com), which carries only short
abstracts/keywords rather than the full judgment text.
