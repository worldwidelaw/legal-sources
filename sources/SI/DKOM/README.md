# SI/DKOM — Državna revizijska komisija (Public Procurement Review Decisions)

Full-text decisions (odločitve) of Slovenia's **Državna revizijska komisija za
revizijo postopkov oddaje javnih naročil** (DKOM) — the independent
quasi-judicial body that decides legal-protection (revizija) complaints in public
procurement procedures under the ZPVPJN. DKOM decisions are binding,
administrative-jurisdictional case law.

## Source

- Listing: <https://www.dkom.si/sl/revizijske-zadeve/odlocitve-dkom/> — embeds all
  ~7,500 decision IDs in a single page (newest first, no pagination).
- Decision page: `https://www.dkom.si/sl/revizijske-zadeve/odlocitve-dkom/{id}/` —
  born-digital HTML; full text in `<div class="decision-content">`, case number and
  decision date in `<span class="date">` elements.
- Open data: also registered on Slovenia's OPSI portal
  (`podatki.gov.si` — "Zbirka izdanih odločitev Državne revizijske komisije").

## Data

- **Type:** case_law
- **Language:** Slovenian (sl)
- **Coverage:** ~7,500 procurement legal-protection decisions
- **Full text:** yes — born-digital HTML, no OCR needed
